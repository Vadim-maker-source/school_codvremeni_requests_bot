# Перенос на VPS

Назначение: 152.234.209.198, /opt/requestsbotweb. Docker Compose: PostgreSQL 18, API, Next.js, aiogram. Существующие сервисы VPS сохраняются. Web слушает только 127.0.0.1:3080; БД/API наружу не публикуются. Существующий Nginx проксирует HTTPS на web.

HTTPS: сертификат IP от Let's Encrypt с отдельным Certbot и собственным timer для короткого срока действия; HTTP-01 через отдельный webroot. HTTPS завершается на loopback-порту 38443, существующий TLS stream направляет туда только IP/пустой SNI. Существующие домены остаются на своих маршрутах.

Этапы: проверка VPS → Docker/сборка → HTTP-01/сертификат → остановка локальной записи и polling → pg_dump без сессий/попыток входа → восстановление с проверкой количества строк и миграций → запуск VPS → HTTPS/cookies/вход/health/бот/перезапуск/резервные копии.

Переносятся существующие заявки, учётные записи, история и Telegram-привязки. Активные веб-сессии не переносятся. Два polling одного токена не запускаются. Секреты и ключи не входят в образ и репозиторий. Локальная БД и дамп сохраняются для возврата. На VPS включается ежедневный pg_dump с ограниченным доступом.

Критерии: доверенный IP-сертификат и HTTP→HTTPS; безопасные cookies; вход прежними учётными данными; совпадающие данные; все контейнеры healthy; один polling; подтверждённый сценарий web/API без тестовых сообщений в чужие чаты; проверка продления сертификата; существующий Nginx проходит тест.
